# Use of Super Intelligence (SI) in FarmSmart

FarmSmart was built for the NASA Space Apps Challenge 2026 by a human team working with SI tools. This note says
where SI was used. Full detail: [docs/SI_USE_DISCLOSURE.md](docs/SI_USE_DISCLOSURE.md).

- **Code:** most of the code in this repository (web app in `web/`, API in `fieldshift/`, scripts and tests) was written
  with an SI coding assistant (Anthropic Claude, via Claude Code), directed, reviewed and tested by the team.
- **Text and documentation:** the README, docs, in-app text and the video script were drafted with SI and edited by the team.
- **Video:** the 30-second showcase video is a screen recording of the real app with real data, recorded by an
  SI-written script. Every frame carries a visible mark: "Real app · real data · SI-assisted recording · music generated with SI".
- **Audio:** the video's background music was generated by SI-written code (`qc/video/showcase/music2.py`,
  synthesised from scratch, no samples). This is also stated in the video file's metadata.
- **Data:** no data was generated by SI. Every number in the app comes from real public sources (NASA, USDA, NOAA and
  others, listed in [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)) or from the app's own models run on that data.
- **In the app:** model outputs are marked with a green "SI" button showing their confidence and reasons.
- **No NASA branding:** no NASA logos, insignia or mission identifiers were generated or used.

FarmSmart supports farmer judgment and never replaces it.
