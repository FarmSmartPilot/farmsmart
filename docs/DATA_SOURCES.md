# Data sources

Verified by the research agent on **2026-11-14**. Test site: Story County, Iowa (42.03, −93.47), with a box of about 65 ha. Full copy-paste templates and response notes are in `docs/reference/ENDPOINTS.md`. Licence and attribution strings for the UI are in `docs/LICENSES.md`.

Key column: **open** = no key · **EDL** = Earthdata Login token (`EARTHDATA_TOKEN` in `.env`) · **key** = free API key in `.env`.
Tested column: HTTP status from curl on 2026-11-14. "not tested" means we only researched it.

Rule for the UI: anything coarser than the field (POWER ≈ 50 km, SMAP 9 km, IMERG 10 km, GRACE ≈ 300 km effective, NEX-GDDP 25 km, MODIS 250 m–1 km) is labelled with its scale, e.g. "regional value (≈50 km)".

## Findings that change the plan

1. **POWER precipitation (`PRECTOTCORR`) is MERRA-2 bias-corrected, not IMERG** (API metadata). Show it as "regional value (≈50 km)". Use IMERG for satellite rain.
2. **POWER `EVPTRNS` is an energy flux (MJ/m²/day)**, not mm. Divide by 2.45. `GWET*` values are wetness fractions (0–1), not volumetric soil moisture.
3. **CDL polygons: use the SCINet `CDL_WM` ImageServer.** It returns all years at a point in one call and per-year histograms for a polygon, and it holds the new 10 m CDL for 2024–2025. The CropScape bbox `GetCDLStat`/`GetCDLFile` failed today.
4. **CSB is keyless through the SCINet FeatureServer, layer 0**, with lower-case field names and 2017–2024 sequences. That gives US field outlines and rotation history in one call.
5. **Use FTW `ftw/global-data`**, not `kerner-lab`, which is the benchmark and has no US data.
6. **NEX-GDDP-CMIP6 point series work through NCCS THREDDS NCSS** (CSV, < 7 s per model-year-variable). Open-Meteo's climate API stops at 2050.
7. **ECOSTRESS Collection 3 (v003) now exists in CMR, but AppEEARS still serves v002.**
8. **GIBS GRACE layer stops at 2022-07.** Draw GRACE maps from the mascon NetCDF itself (44 MB, through 2026-09).
9. **USGS legacy `gwlevels` service is retired (403).** Use `api.waterdata.usgs.gov` `field-measurements` (parameter 72019).
10. **The FAOSTAT API now needs a token.** Use the bulk zip.
11. **PRISM has no point time-series API**: download grids and sample them locally. 800 m is free since 2025.
12. **EOX: only the 2016 mosaic is CC BY.** Later years are non-commercial share-alike.
13. **Economics (data-ground, 2026-11-14).** ERS Costs and Returns CSV links are `/media/{id}/{crop}.csv?v=…` on the landing page; ids change per release, so `fieldshift/ingest/econ.py` scrapes them. Rice and peanuts use their own ERS regions (e.g. "California", "Gulf Coast"), not farm resource regions. County→region link: `https://www.ers.usda.gov/sites/default/files/images/reglink.xls` (needs `xlrd`). **Pink Sheet `Sorghum` and `Barley` stopped in 2020-08**; there is no oats or canola-seed series. Pink Sheet prices are world export references (e.g. maize FOB US Gulf), not farm-gate prices.
