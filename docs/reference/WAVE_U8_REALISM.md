## Backend (X-back)
1. **Conservation cost-share (`money` response → `costshare`)**: USDA NRCS EQIP payment schedule rates for Cover Crop (practice 340) — and Conservation Crop Rotation (328) if available — for the field's state, current fiscal year, per acre, with the scenario names (e.g. "Basic", "Multiple species") and the historically-underserved rate where published. Find the official machine-readable or downloadable source (NRCS publishes state payment schedules); commit small per-state snapshots for the pilot states (IA, KS, CA) + a generic fetch for others; `available:false` + reason if not reachable. Shape: `{"available": true, "state": "IA", "fiscal_year": 2026, "items": [{"practice": "340", "name_en": "Cover crop (basic)", "usd_ac": 58.12, "notes": "..."}], "source": "...", "url": "...", "caveat_en": "Payments need an approved NRCS contract; amounts and eligibility vary."}`.
2. **Nitrogen credit (`money` → each option's positions get `n_credit_lb_ac`)**: from the rules engine's legume N credit already applied to the following crop (`n_delta` / sourced ranges; use the midpoint and give `n_credit_range_lb_ac`), so the calculator can value it with the fertilizer price. Also return `fertilizer_n_price`: latest World Bank urea $/mt from `data/reference/wb_prices_monthly.json` and the derived $/lb N (urea 46 % N), with the month.
3. **Season outlook `GET /api/fields/{fid}/outlook`**: NOAA Climate Prediction Center official 3-month (and 1-month) outlook probabilities at the field point: the leads for the next three overlapping seasons, temperature and precipitation categories (above / near / below normal) with probabilities, issue date. Use CPC's published GIS/text products (find the current official format; no key). US only (CPC covers the US); elsewhere `available:false` with "NOAA outlooks cover the United States". Shape: `{"available": true, "issued": "2026-11-20", "items": [{"season": "DJF", "label_en": "Dec–Feb", "temp": {"category": "above", "p": 0.40}, "precip": {"category": "equal_chances", "p": 0.33}}], "source": "NOAA CPC", "url": "...", "note_en": "Chances for a large region, not a forecast for your field."}`. Cache 12 h.
4. **Farmer's soil test**: `compare` and `money` accept `farm.soil_test = {"ph": 6.1, "om_pct": 3.4, "year": 2025}`; when present it overrides the mapped soil pH and organic matter for the rules (pH fit, lime) and the soil-carbon start, and the evidence says "your soil test (2025)". Confidence data flags lose the "mapped soil" penalty. Without it, outputs are byte-identical (verify the 8 pilots).
Verify everything with real calls on :8051 for Story County, Finney irrigated and Punjab; report.
