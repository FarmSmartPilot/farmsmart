# 30-second showcase video (4K, 24 fps)

Output: `farmsmart_30s_4k24.mp4` (3840x2160, 24 fps, H.264 + AAC) and `docs/demo/farmsmart_30s.en.srt`.

1. Start the app (`start.ps1`: API on :8000, web on :5173).
2. `node qc/video/showcase/record4k.mjs`: records the real app in slow motion (5x) with true 4K screenshots;
   captions, cursor and title cards are page overlays. Frames + `timeline.json` go to `qc/video/showcase/work/`.
3. `TRIM_START=0.5 LENGTH=30 python qc/video/showcase/build.py <out_dir>`: 24 fps video, original music from
   `music.py` (synthesised in code, no samples), loudness -16 LUFS, and the `.srt`.

SI use: the recording is driven by an SI-written script; the music is generated by SI-written code. Both are marked
in the video's corner and listed in docs/SI_USE_DISCLOSURE.md.

## Version 2: whole farm (current)

`record_farm.mjs` + `build_wholefarm.py` + `music2.py` (120 BPM, cues from the recording's marks) make
`farmsmart_30s_wholefarm_4k24.mp4` and `docs/demo/farmsmart_30s_wholefarm.en.srt`:
one field at a time -> Add to my farm -> the 3-field sample farm -> the page's stress test (driest years, prices 20 % lower)
-> Find the best plan (change one field) -> apply. `TRIM_START=0.3 LENGTH=30 python build_wholefarm.py <out_dir>`.
In normal years no single change raises profit and lowers risk on the sample farm, so the video uses the stress test and
says so on screen.
